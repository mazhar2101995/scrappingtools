4. OPENCART UNIVERSAL BRIDGE V2.0 (ZERO-CONFIGURATION ENGINE)
====================================================================================================
Location in Code: packages/connectors/src/bridge/saas_bridge.php
File Size: ~14 KB (Self-Contained Single File)

Engineering Highlights & Problem Fixes:
1. Dynamic MySQL Schema Introspection:
   - Problem Solved: OpenCart tables in strict MySQL mode throw errors like:
     "Field 'upc' doesn't have a default value" or "Field 'date_available' doesn't have a default value".
   - Solution: The bridge runs "SHOW COLUMNS FROM oc_product" dynamically on startup. It detects
     every column in the user's specific database schema and automatically fills appropriate defaults
     (e.g., '' for text, 0 for numeric, '2000-01-01' for dates), preventing ANY SQL strict mode exceptions.

2. Product Visibility in Admin Catalog:
   - Problem Solved: Products were inserted into oc_product but did not appear in OpenCart Admin Product List.
   - Solution: OpenCart requires records in both oc_product_description (with language_id matching store default)
     and oc_product_to_store (store_id = 0). The bridge guarantees these entries are created automatically.

3. Automated Remote Image Mirroring:
   - Problem Solved: OpenCart cannot display thumbnails for external HTTPS URLs.
   - Solution: The bridge downloads remote manufacturer images, saves them directly into OpenCart's
     image/catalog/products/ directory, and stores relative paths (catalog/products/filename.jpg) in oc_product.
     Result: High-resolution thumbnails render natively in OpenCart storefront and admin.

4. Multi-Field Rich HTML Descriptions:
   - Combines multiple extracted fields (Overview, Features, Specifications Table, and Compatible Models)
     into a beautifully formatted HTML description block before writing to oc_product_description.

5. Public One-Click Bridge Download Endpoint:
   - GET /api/v1/stores/download-bridge returns the latest pre-configured PHP bridge file directly.
